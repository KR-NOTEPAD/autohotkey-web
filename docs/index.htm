AutoHotkey Web

AutoHotkey Web은 AutoHotkey v1.1.37.02를 포크해서 만든 실행 엔진입니다. 문법은 v1과 같아서 기존 스크립트를 그대로 쓸 수 있고, 아래 기능들이 엔진 안에 들어 있습니다.

  • WebGui — HTML/CSS/JS(React·Vue 등) UI를 WebView2로 띄우고 AHK와 연결하는 하이브리드 앱 명령.
  • TextCls / TextNN — ONNX 기반 한국어 텍스트 분류·즉석 학습 내장 함수.
  • WsServer / Cdp.ahk — 내장 WebSocket 서버로 Chrome(CDP) 제어.
  • 메소드 체이닝 / JSON — " a,b ".Trim().Split(",").Join("|"), arr.Sort("N").Map(fn).Sum(), JsonParse/JsonStringify.
  • 한글 OCR — 딥러닝(PaddleOCR) OcrImageAI/OcrScreenAI + Windows 내장 OcrImage/OcrScreen.
  • 암호화 — SHA·HMAC, AES-256-GCM 문자열/파일, 비밀번호 해시, DPAPI, ECDSA 서명, 보안 난수.
  • 컴파일 / EXE 암호화 — AhkWeb2Exe, 스크립트 자동 난독화·압축, 안티치트 오탐을 줄이는 중립 창 클래스/식별자.
  • 툴킷 — HTTP·병렬요청·WebSocket 클라이언트, ZIP·인코딩·휴지통, 이미지서치 전체·템플릿매칭·QR·클립보드 이미지, 문자열 유사도·CSV.
원래 AutoHotkey와 창 클래스, 레지스트리 위치, 컴파일 표시가 모두 달라서 한 PC에 같이 설치해도 서로 영향을 주지 않습니다.

설치 (권장)

installer\output\AutoHotkeyWeb_Setup_*.exe를 실행하면 전부 자동 설치됩니다(한국어/영어 마법사).

  • 엔진·컴파일러·문서를 C:\Program Files\AutoHotkey Web에 설치.
  • .ahkw 파일 형식 등록(더블클릭 실행, 우클릭 Edit→SciTE4, Compile→EXE).
  • 우클릭 → 새로 만들기 → "AutoHotkey Web Script" 추가(한글 포함 UTF-8 BOM 템플릿).
  • SciTE4에서 .ahkw 구문 강조·실행·디버그·컴파일·자동완성 자동 구성.
  • WebView2 런타임 유무 점검, 제거 프로그램 포함.
Windows의 "새로 만들기" 메뉴는 한 단계 평면 목록이라, 항목은 stock "AutoHotkey Script" 옆에 "AutoHotkey Web Script"로 나타납니다. 생성 파일 확장자는 .ahkw이며, 한글 내용이 깨지지 않도록 템플릿은 UTF-8 BOM으로 복사됩니다.

직접 빌드

빌드

REM 1) WebView2 SDK 받기 (최초 1회)
powershell -ExecutionPolicy Bypass -File fetch_webview2.ps1

REM 2) 엔진 빌드 (x64 Native Tools Command Prompt 권장)
build.bat
REM -> AutoHotkeyWeb.exe 생성

REM 3) 컴파일러 + .bin 베이스 빌드
cd compiler
build_compiler.bat
REM -> AhkWeb2Exe.exe, AutoHotkeyWeb.bin

실행 / 컴파일

작업명령
스크립트 실행AutoHotkeyWeb.exe myapp.ahk
단일 EXE로 컴파일AhkWeb2Exe.exe /in myapp.ahk /out myapp.exe

SciTE4AutoHotkey에서 개발

설치 프로그램이 SciTE4 폴더에 AutoHotkeyWeb.properties를 만들고 SciTEGlobal.properties에서 import 합니다(PC 전체 적용). .ahkw 파일에만 적용되므로 기존 .ahk 설정은 바뀌지 않습니다.

  • .ahkw를 열면 AHK 구문 강조와 글꼴이 그대로 적용됩니다(플랫폼 선택 불필요).
  • F5 실행 / F7 디버그 / Ctrl+F7 컴파일 / F1 도움말이 이 엔진을 사용합니다.
  • 새 함수와 체이닝 메소드가 자동완성/콜팁(scite\ahkweb.api)에 등록됨.
디버거는 stock SciTE4의 DBGp 하네스를 그대로 씁니다(appid를 "AutoHotkey"로 유지).

라이선스

AutoHotkey Web은 AutoHotkey v1.1과 같은 GPLv2를 따릅니다. 이 소스로 만든 프로그램을 배포할 때는 AhkWeb2Exe로 컴파일한 .exe라도 대응하는 소스 전체를 GPLv2로 공개해야 합니다. 컴파일할 때 스크립트를 알아보기 어렵게 섞어 넣는 것과 소스 공개 의무는 별개입니다.

함께 배포하는 ONNX Runtime과 miniz, cJSON, qrcodegen은 MIT 라이선스이고, WebView2 SDK는 Microsoft의 약관을 따릅니다. 따로 받는 모델은 kor_unsmile과 한국어 PP-OCRv5가 Apache-2.0, KoSimCSE가 CC BY-SA 4.0입니다. KoSimCSE는 출처를 밝혀야 하고 고쳐서 배포하면 같은 라이선스로 공개해야 합니다. 출처 표시 문구는 저장소의 MODELS.md에 있습니다.

"AutoHotkey"는 원래 상표권자의 상표이고, 이 포크는 AutoHotkey 프로젝트와 관계가 없습니다. 컴파일한 exe의 창 클래스와 버전 정보에는 이 이름이 들어가지 않지만, 개발용 인터프리터는 SciTE4 디버거 때문에 이름을 남겨 두었습니다. 만든 프로그램 이름에 "AutoHotkey"를 넣으려면 먼저 상표 사용 조건을 확인해 주세요.

라이선스 전문은 배포물의 LICENSE 파일에 있습니다. 이 페이지는 이해를 돕기 위한 요약이고 법률 자문이 아닙니다.

CDP 웹 제어 — WsServer* / Cdp.ahk

실제 Chrome 을 Chrome DevTools Protocol(CDP) 로 제어합니다. 엔진에는 CDP 중계에 필요한 WebSocket 서버가 내장되어 있어(WsServer*), 별도 DLL 이나 DllCall 없이 동작합니다. 고수준 API 는 번들 라이브러리 Lib\Cdp.ahk 로 제공합니다.

구성: AHK(엔진 내장 WsServer) ↔ 작은 Chrome 확장(cdp_extension) ↔ chrome.debugger API ↔ 브라우저 탭. 확장은 서버에 붙어 AHK 가 보내는 CDP 명령을 탭에 중계하고 결과를 돌려줍니다.

준비 (1회)

  1. Chrome 에서 chrome://extensions 열기 → 우상단 개발자 모드 켜기.
  2. "압축해제된 확장 프로그램 로드" → 예제의 examples\02_CDP_웹제어\cdp_extension 폴더 선택.
  3. 스크립트에서 WsServerStart() 로 서버를 켜면 확장이 자동으로 연결합니다(기본 포트 19222).

저수준 내장 함수 (WebSocket 서버)

함수설명
WsServerStart([Port:=19222])지정 포트에서 수신 시작. 성공 1/실패 0.
WsServerStop()서버 중지(1).
WsServerPort()현재 포트(중지 상태면 0).
WsServerClients()연결된 클라이언트 수(확장이 붙었는지 확인).
WsServerPending()수신 대기 중인 메시지 수.
WsServerSend(Text)텍스트 프레임을 모든 클라이언트에 브로드캐스트.
WsServerRecv([TimeoutMs:=0])수신 메시지 하나를 꺼내 반환(없으면 "").
WsServerLastError()마지막 오류 문자열.
WsServerAvailable()항상 1(엔진 내장).

JSON / Base64 보조 함수

val := JsonGet(JsonText, Path)
raw := Base64Decode(B64Text)

JsonGet 은 JSON 문자열에서 Path(점/대괄호 표기)로 값을 꺼냅니다. CDP 응답 파싱에 쓰입니다.

반환불리언은 문자열 "true"/"false", null 은 "null" 로 반환됩니다. 따라서 if (JsonGet(r, "result.value") = "true") 처럼 비교할 수 있습니다.
Base64Decode 는 base64 문자열을 디코드해 반환합니다(스크린샷 등 CDP 바이너리 결과 처리용).

고수준 API — Lib\Cdp.ahk

대부분의 스크립트는 저수준 함수 대신 번들 라이브러리를 씁니다. 이 파일은 WsServer 서버와 확장을 감싸 명령/응답을 객체로 다룹니다. 외부 플러그인 의존이 제거되어 있어 #Include 만 하면 됩니다.

#Include %A_ScriptDir%\..\..\Lib\Cdp.ahk
cdp := new Cdp()
서버 기동 + 확장 연결 대기.
tab := cdp.goto(Url)
활성 탭을 URL 로 이동하고 로드 완료까지 대기.
val := tab.evaluate(Js)
페이지 컨텍스트에서 JS 실행 후 결과 반환.
정확한 메서드 구성은 번들 Lib\Cdp.ahk 상단 주석과 examples\02_CDP_웹제어\app.ahk 를 참고하세요. 확장이 아직 안 붙었으면 goto 가 연결을 기다립니다.

예제 (저수준)

; 서버를 켜고 확장 연결을 기다린 뒤, 활성 탭을 example.com 으로 이동
if (!WsServerStart(19222)) {
    MsgBox, % "서버 시작 실패: " WsServerLastError()
    ExitApp
}
; 확장이 연결될 때까지 대기
Loop {
    if (WsServerClients() >= 1)
        break
    Sleep, 200
} Until (A_Index > 50)   ; 최대 10초

; 확장 프로토콜에 맞춘 CDP 명령 전송(예시 형식)
WsServerSend("{""id"":1,""method"":""Page.navigate"",""params"":{""url"":""https://example.com""}}")

; 응답 수신 + 파싱
r := WsServerRecv(3000)
if (r != "")
    MsgBox, % "frameId=" JsonGet(r, "result.frameId")
고수준 흐름(이동→제목/링크 추출→임의 JS 실행)을 WebGui UI 와 묶은 완성 예제는 examples\02_CDP_웹제어 에 있습니다.

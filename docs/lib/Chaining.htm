메소드 체이닝 / JSON

문자열·배열·객체에 메소드를 이어 붙여 쓸 수 있습니다. #Include나 래퍼 클래스 없이, 모든 값에 바로 동작합니다. 문법은 v1 그대로입니다.

"  hello world ".Trim().Title().Replace("World", "AHK")   ; "Hello AHK"
"a,b,,c".Split(",").Compact().Join("|")                 ; "a|b|c"
[3, 1, 2].Sort("N").Reverse().Join("-")                 ; "3-2-1"
staff.Where("dept", "개발").SortBy("age").Pluck("name").Join(", ")
cfg := FileText.JsonParse(), cfg.Get("app.window.w")
우선순위(기존 스크립트 보호): 객체의 키, 클래스 메소드, base 객체, stock 내장 메소드(Length/Push/Count…)가 먼저 처리되고, 그 다음에야 아래 메소드가 동작합니다. 문자열도 "".base.Trim := Func("My")처럼 스크립트가 정의한 확장이 있으면 그것이 우선합니다.
v1 파서 제약: {a:1}.Keys()처럼 객체 리터럴 바로 뒤에는 메소드를 붙일 수 없습니다(변수에 담은 뒤 호출). 배열 리터럴 [1,2].Join()과 문자열 리터럴은 됩니다. 또 "" [1,2]처럼 값 뒤에 공백+[가 오면 인덱싱으로 해석되니 변수를 쓰세요.

배열 / 객체 메소드

콜백은 함수 이름 문자열, Func 객체, BoundFunc 모두 됩니다. 콜백에는 (값, 키, 배열)이 전달되며, 선언한 매개변수 개수만큼만 넘어갑니다. "새 배열"이라고 쓴 메소드는 원본을 바꾸지 않습니다.

Sort 옵션: 문자열 "N"(숫자) "D"(내림) "C"(대소문자 구분) "NAT"(자연 정렬, a2<a10), 비교 함수 fn(a, b), 또는 객체 {by:"age", desc:true, numeric:true, natural:true, cs:true, fn:Func("…")}.

Where 연산자: = == != <> > >= < <= contains startswith. Slice는 1부터, 끝 포함, 음수는 뒤에서부터(Slice(-2) = 마지막 2개).

JsonParse / JsonStringify

Obj  := JsonParse(JsonText)
Text := JsonStringify(Value [, Indent])
  • 배열은 1부터 시작하는 AHK 배열, true/false→1/0, null→빈 문자열, 소수는 숫자 문자열("1.5")로 보관해 표시가 깨지지 않습니다.
  • Indent: 칸 수(예: 2) 또는 문자열(예: "`t"). 생략하면 한 줄.
  • 키가 1..n 으로 연속인 객체는 JSON 배열, 그 외는 JSON 객체. 정확한 JSON 숫자 모양의 문자열(1.5, -3)은 숫자로, "007"·"0x10"은 문자열로 씁니다.
  • v1 객체의 키 순서는 정수 → 문자열(알파벳순)입니다.

예제

people := [{name: "Kim", age: 30}, {name: "Lee", age: 20}, {name: "Park", age: 40}]
MsgBox % people.SortBy("age").Pluck("name").Join(" → ")     ; Lee → Kim → Park
MsgBox % people.Where("age", 25, ">").ToJson(false)
cfg := {}
cfg.Set("window.size.w", 800).Set("theme", "dark")
FileAppend, % JsonStringify(cfg, 2), config.json

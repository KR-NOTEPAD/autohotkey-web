암호화 · 해시 · 서명

Windows CNG(BCrypt) 기반 암호 기능을 엔진에 내장했습니다. 문자열은 내부에서 UTF-8로 처리되어 한글이 그대로 왕복하며, 바이너리 결과는 Base64 또는 hex 문자열로 주고받습니다.

해시 / 체크섬

함수반환
SHA256(text) SHA1 SHA384 SHA512 MD5소문자 hex
HMAC(text, key) / HMAC512(text, key)HMAC-SHA256 / SHA512 hex
CRC32(text) Adler32 Fnv1a체크섬 hex
SHA256File(path) CRC32File(path)파일 해시

AES-256-GCM 암호화 (비밀번호 기반)

Token := EncryptPassword(PlainText, Password [, Iterations := 100000])
Plain := DecryptPassword(Token, Password)
OK    := EncryptFile(InPath, OutPath, Password [, Iterations := 100000])
OK    := DecryptFile(InPath, OutPath, Password)

PBKDF2-SHA256으로 32바이트 키를 만들고 AES-256-GCM으로 암호화합니다. 솔트(16B)와 nonce(12B)는 매번 새로 생성되며, 토큰은 v1:salt:nonce:tag:cipher 형식입니다. 비밀번호가 틀리거나 한 바이트라도 변조되면 DecryptPassword는 빈 문자열, DecryptFile은 0을 반환합니다(인증 태그 검증).

비밀번호 저장

Hash := HashPassword(Password [, Iterations := 100000])   ; "pbkdf2$iter$salt$hash"
OK   := VerifyPassword(Password, Hash)

로그인 비밀번호처럼 "맞는지 확인만" 하면 되는 값은 암호화하지 말고 이 해시만 저장하세요.

DPAPI

B64  := DpapiProtect(Text [, Entropy, MachineScope := false])
Text := DpapiUnprotect(B64 [, Entropy])

비밀번호 없이 현재 Windows 사용자(MachineScope=true면 이 PC)만 풀 수 있게 보호합니다. API 키·토큰을 설정 파일에 저장할 때 유용합니다.

ECDSA P-256 전자서명

Pair := EcdsaKeyPair()                 ; "개인키B64:공개키B64"
Sig  := EcdsaSign(Text, PrivateKeyB64)
OK   := EcdsaVerify(Text, SigB64, PublicKeyB64)

개인키는 비밀로 보관하고 공개키만 배포합니다. 내용이 바뀌면 EcdsaVerify가 0을 반환합니다(업데이트 파일·라이선스 검증 등).

문자열 메소드로도 쓸 수 있습니다: pw.SHA256(), memo.Encrypt("pw").Decrypt("pw"), txt.Base64().

예제

token := EncryptPassword("계좌 메모", pw)
FileAppend, %token%, memo.enc
FileRead, t, memo.enc
MsgBox % DecryptPassword(t, pw)

kp := StrSplit(EcdsaKeyPair(), ":")
sig := EcdsaSign("release-1.2.zip:" SHA256File("release-1.2.zip"), kp[1])

전체 예제: examples\05_암호화\crypto_basics.ahkw, file_vault.ahkw(폴더 금고 + SHA-256 무결성 + JSON 목록)

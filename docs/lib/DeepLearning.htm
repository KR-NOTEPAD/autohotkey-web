딥러닝 — TextCls / TextNN

엔진에 내장된 ONNX 기반 텍스트 AI 함수입니다. 별도 플러그인이 전혀 필요 없으며, DllCall 도 쓰지 않습니다. 두 묶음으로 나뉩니다.

  • TextCls* — 사전학습된 ONNX 분류 모델 폴더(model.onnx/model_int8.onnx + labels.txt + vocab.txt)로 문장을 분류.
  • TextNN* — 한국어 임베딩 백본(.onnx) + C++ MLP 헤드를 즉석 학습해 .ntc 모델을 만들고 분류.
필수 조건: 엔진(AutoHotkeyWeb.exe) 옆에 onnxruntime.dll 이 있어야 합니다. 설치 프로그램은 이를 자동 배치하며, 모델은 "딥러닝 모델" 구성요소로 {app}\models 에 설치됩니다. onnxruntime.dll 은 지연 로드(delay-load)되므로, 딥러닝을 쓰지 않는 스크립트는 DLL 이 없어도 정상 실행됩니다.

가용성 확인

ok := TextClsAvailable()   ; 1/0
ok := TextNNAvailable()   ; 1/0 (동일한 ONNX 게이트)

onnxruntime.dll 이 로드 가능하면 1, 아니면 0. 두 함수는 같은 ONNX 런타임 상태를 반환합니다.

텍스트 분류 (TextCls*)

TextClsVerdict(ModelDir, Text [, ThrPct:=50, MaxLen:=128])

r := TextClsVerdict(ModelDir, Text [, ThrPct, MaxLen])

이진(선/악) 판정을 한 줄 문자열로 반환합니다. 처음 호출 시 모델이 자동 로드됩니다(기본 int8 사용).

ModelDir
모델 폴더 경로(예: {app}\models\kor_unsmile).
Text
분류할 문장.
ThrPct
악성 판정 임계값(%). 기본 50.
MaxLen
토큰 최대 길이. 기본 128.

반환: "판정,라벨,악성확률,정상확률" 형식. 예: 악,욕설/비속,0.9855,0.0167. 판정은 악 또는 선. 라벨에는 쉼표가 없으므로 StrSplit(r, ",") 로 4개 필드로 나눌 수 있습니다.

TextCls(ModelDir, Text [, MaxLen:=128])

probs := TextCls(ModelDir, Text [, MaxLen])

라벨별 확률을 "라벨,확률;라벨,확률;..." 형식으로 반환합니다(다중 라벨 모델의 전체 분포 확인용).

TextClsLabels(ModelDir)

labels := TextClsLabels(ModelDir)

모델의 라벨 목록을 줄바꿈으로 구분해 반환합니다.

함수설명
TextClsLoad(ModelDir [, UseInt8:=1])모델을 미리 로드(1/0). 생략해도 Verdict/Cls 첫 호출 시 자동 로드.
TextClsUnload()로드된 분류 모델을 메모리에서 해제(1).
TextClsLastError()마지막 오류 문자열.

텍스트 학습 (TextNN*)

TextNNTrain(Backbone, Dataset, Model [, Epochs:=300, Hidden:=64, MaxLen:=64, Pool:=0])

n := TextNNTrain(Backbone, Dataset, Model [, Epochs, Hidden, MaxLen, Pool])

임베딩 백본으로 데이터셋을 벡터화한 뒤, 작은 MLP 분류 헤드를 학습해 .ntc 모델 파일로 저장합니다.

Backbone
임베딩 ONNX 경로(예: {app}\models\kor_embed\kosimcse_embed_int8.onnx).
Dataset
라벨<TAB>문장 형식의 UTF-8 TSV 경로. # 로 시작하는 줄은 주석.
Model
학습 결과를 저장할 .ntc 경로.
Epochs / Hidden / MaxLen
학습 반복수 / 은닉층 크기 / 토큰 길이.
Pool
풀링 방식(0=mean).

반환: 학습에 사용된 문장 수(실패 시 0 — TextNNLastError() 확인).

TextNNClassify(Model, Text [, TopK:=3])

r := TextNNClassify(Model, Text [, TopK])

학습한 .ntc 모델로 문장을 분류합니다. 반환: "라벨,확률;라벨,확률;..."(확률 내림차순, 상위 TopK개).

함수설명
TextNNInfo(Model)"백본|차원|풀링|라벨목록". 예: ...int8.onnx|768|mean|E,I.
TextNNLoad(Model)모델을 미리 로드(1/0).
TextNNUnload()로드된 NN 모델 해제(1).
TextNNLastError()마지막 오류 문자열.

예제

1) 악성/정상 분류

ModelDir := A_ScriptDir "\models\kor_unsmile"
if (!TextClsAvailable()) {
    MsgBox, onnxruntime.dll 이 필요합니다.
    ExitApp
}
r := TextClsVerdict(ModelDir, "오늘 정말 행복한 하루였어요")   ; 선,...,0.0055,0.9904
parts := StrSplit(r, ",")
MsgBox, % "판정=" parts[1] "  악성확률=" parts[3]

2) 감정 모델 즉석 학습 후 분류

backbone := A_ScriptDir "\models\kor_embed\kosimcse_embed_int8.onnx"
tsv   := A_Temp "\senti.tsv"
model := A_Temp "\senti.ntc"
FileDelete, %tsv%
FileAppend,
(
긍정`t정말 좋아요 최고예요
긍정`t너무 만족스럽고 행복해요
부정`t별로예요 실망했어요
부정`t다시는 안 올 것 같아요
), %tsv%, UTF-8

n := TextNNTrain(backbone, tsv, model, 300, 64, 64, 0)   ; 학습 문장 수
r := TextNNClassify(model, "생각보다 정말 괜찮네요", 1)   ; "긍정,0.98"
MsgBox, % "학습 " n "문장`n결과: " r
백본·분류 모델은 용량이 큽니다(int8 기준 각 ~110MB). 첫 추론/학습 때 모델 로딩에 수 초~수십 초가 걸릴 수 있고, 이후 호출은 빠릅니다. WebGui 와 결합하면 웹 UI 로 결과를 바로 시각화할 수 있습니다(예제 1·3 참고).

한글 OCR (AI + Windows)

두 가지 OCR 엔진이 내장되어 있습니다.

엔진함수특징
AI OCR (권장)OcrImageAI OcrScreenAI OcrAIErrorPaddleOCR(PP-OCRv5) ONNX. 한글·영문·숫자·기호 혼합, 차대번호·세로글씨 옵션. onnxruntime.dll + models\ocr 필요.
Windows OCROcrImage OcrScreen OcrLanguages모델 없이 OS 언어팩 사용. 가볍고 빠름.

OcrImageAI / OcrScreenAI

Text := OcrImageAI(ImagePath [, ModelDir, Opts])
Text := OcrScreenAI(X, Y, W, H [, ModelDir, Opts])
Err  := OcrAIError()
ModelDir
비우면 엔진 폴더의 models\ocr\(det.onnx, rec_korean_v5.onnx, korean_dict_v5.txt, cls.onnx).
Opts
공백으로 구분, 조합 가능:
  • enhance 인식 전 화질 향상(작은 글자·흐림), scale=300 확대 %
  • cls 180° 뒤집힌 글자 보정, rot=auto 세로 글자 자동 회전(rot=90|180|270 고정)
  • vin 차대번호 전용(0-9·A-Z, I/O/Q 제외), digits alnum upper allow=0-9A-Z 허용 문자
  • data 줄마다 x,y,w,h,score<TAB>텍스트 좌표·점수 포함
  • denoise 카메라 사진 노이즈 제거, sr 딥러닝 초해상도(models\realesrgan_x4.onnx 필요, 느림)

반환: 인식 텍스트(줄바꿈 구분). 실패 시 빈 문자열 → OcrAIError()로 원인 확인. 첫 호출은 모델 로드로 1~3초, 이후는 캐시됩니다. 화면 OCR은 임시 파일 없이 메모리로 캡처합니다.

OcrImage / OcrScreen / OcrLanguages

Text  := OcrImage(ImagePath [, Lang])
Text  := OcrScreen(X, Y, W, H [, Lang])
Langs := OcrLanguages()        ; 예: "ko en-US"

Lang을 비우면 사용자 언어 프로필을 따릅니다. 한국어 OCR 언어팩이 없으면 OcrLanguages()에 ko가 없습니다(설정 → 시간 및 언어 → 언어에서 한국어 추가).

함께 쓰면 좋은 함수

  • SelectRegion() 마우스로 영역 드래그 → "x,y,w,h"
  • ClipboardImageToPng(path) Win+Shift+S 캡처를 바로 OCR
  • ImageEnhance(in, out [, scalePct, opts]) 전처리만 따로

예제

r := StrSplit(SelectRegion(), ",")
if (r.Length() = 4)
    MsgBox % OcrScreenAI(r[1], r[2], r[3], r[4], "", "enhance")

vin := OcrImageAI("car.jpg", "", "enhance vin")
lines := OcrImageAI("doc.png").Lines().Compact()      ; 체이닝으로 줄 배열

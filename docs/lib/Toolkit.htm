툴킷 함수

외부 툴킷 기능을 엔진에 내장했습니다. 이름 규칙은 Note_X() → X()(접두사 제거)이며, DLL·Note_Init()·#Include가 필요 없습니다. stock v1에 이미 있는 기능(파일 복사, 프로세스, 마우스, Ini 읽기/쓰기, PixelSearch 등)은 중복으로 넣지 않았습니다.

이름이 바뀐 것: Note_GenKeyPair/Sign/Verify → EcdsaKeyPair/EcdsaSign/EcdsaVerify, Note_Entropy → StrEntropy, Note_Upper/Lower/TitleCase/Repeat/Reverse/PadLeft/PadRight/CountSub → StrUpper/StrLower/StrTitle/StrRepeat/StrReverse/StrPadLeft/StrPadRight/StrCount(v2와 같은 이름). 스크립트에 같은 이름의 함수가 있으면 스크립트 함수가 우선합니다.

WebGui

HTML/CSS/JavaScript로 만든 UI를 WebView2로 창에 띄우고, OS 제어·매크로 로직을 담당하는 오토핫키 스크립트와 비동기 메시지 채널로 연결합니다. 하이브리드 데스크톱 앱의 프런트엔드(React·Vue 등)와 백엔드(AHK)를 잇는 브릿지입니다.

WebGui, Name:SubCommand , Param2, Param3, Param4

Name:을 붙이면 이름 있는 창을 지정합니다. 생략하면 기본 창(1)을 사용합니다. 예: WebGui, Main:Load, index.html.

필요 조건: 대상 PC에 Microsoft Edge WebView2 런타임이 설치되어 있어야 합니다. Windows 10/11 대부분에 기본 포함(Evergreen)되어 있습니다.

하위 명령

New

WebGui, Name:New , Options, Title

숨김 상태의 웹 창을 생성하고 WebView2를 비동기로 초기화합니다.

Options
wNNN 너비, hNNN 높이, -Resize 크기 조절 비활성화.
Title
창 제목 표시줄 텍스트.

Load

WebGui, Name:Load, UrlOrFile

페이지를 탐색합니다. http(s):// URL(예: Vite 개발 서버 http://localhost:5173)이나 로컬 .html 경로(자동으로 file://로 변환)를 받습니다. 코어가 아직 준비 전이면 준비 직후 자동 탐색합니다.

Show

WebGui, Name:Show , Options

창을 표시하고 포그라운드로 가져옵니다. Options에 wNNN hNNN로 크기 조정, Maximize로 최대화.

Hide

WebGui, Name:Hide

창을 파괴하지 않고 숨깁니다.

Expose

WebGui, Name:Expose, Method , FuncName

JS 메서드를 AHK 함수에 연결합니다. 페이지에서 await ahk.call(Method, obj)를 호출하면, AHK 함수가 obj를 JSON 문자열로 받아 실행되고, 반환한 문자열이 JS의 Promise로 돌아갑니다. FuncName 생략 시 Method와 같은 이름의 함수를 사용합니다.

On

WebGui, Name:On, __Event, FuncName

생명주기/웹 이벤트를 AHK 함수에 연결합니다. __Ready(페이지가 ahk.post("__Ready",...) 호출 시), __Close(창 닫기 버튼) 등. 핸들러는 데이터를 JSON 문자열로 받습니다.

Emit

WebGui, Name:Emit, EventName , Data

페이지의 window.ahk.on(EventName) 리스너를 호출합니다. Data는 문자열로 전달됩니다. AHK→JS 방향의 푸시.

Eval

WebGui, Name:Eval, JsCode

페이지에서 임의의 JavaScript를 실행합니다(결과 대기 없음). 반환값이 필요하면 아래 WebGuiGet을 쓰세요.

Html

WebGui, Name:Html, HtmlString

HTML 문자열을 직접 로드합니다(WebView2 NavigateToString). 외부 .html 없이 한 파일로 앱을 만들 때 유용합니다. window.ahk 브릿지는 그대로 동작합니다. 오리진이 about:blank이므로 ES 모듈·fetch가 필요하면 Mount를 쓰세요. (우클릭 → 새로 만들기 → AutoHotkey Web Script 템플릿이 이 방식입니다.)

Mount

WebGui, Name:Mount, HostName, Folder , AccessKind

https://HostName/을 로컬 Folder에 매핑합니다. 이렇게 하면 페이지가 file://가 아니라 진짜 웹 오리진으로 로드되어 ES 모듈 import, fetch/XHR, 서비스 워커가 정상 동작합니다. 실제 SPA(React·Vue dist) 배포에 필수입니다. AccessKind: CORS(기본, 교차 출처 허용) 또는 Deny.

코어는 비동기로 생성되므로 New 직후 Mount를 호출하면 큐에 저장되었다가 첫 Load 직전에 자동 적용됩니다. 순서 걱정 없이 New→Mount→Load로 쓰면 됩니다.

DevTools

WebGui, Name:DevTools

WebView2 개발자 도구 창을 엽니다(개발용). 릴리스 빌드에서는 기본 DevTools가 비활성이지만 이 명령으로 강제로 열 수 있습니다.

Destroy

WebGui, Name:Destroy

창을 닫고 WebView2 리소스를 해제합니다.

브릿지 API (페이지 측 window.ahk)

모든 페이지에 자동 주입되는 window.ahk 객체:

메서드설명
ahk.call(method, params)Promise 반환. Expose된 AHK 함수를 호출하고 반환 문자열로 resolve.
ahk.post(method, params)반환값 없이 이벤트 전송(예: __Ready). On으로 연결.
ahk.on(event, cb)AHK의 Emit 이벤트 수신.
ahk.off(event, cb)리스너 해제.

스레드 모델

WebView2 콜백은 UI 스레드에서 인터프리터 밖으로 들어옵니다. AutoHotkey Web은 콜백에서 스크립트를 직접 실행하지 않고, 메시지를 큐에 넣은 뒤 메인 창에 AHK_WEB_EVENT를 보냅니다. 실제 핸들러 실행은 GUI/핫키 이벤트와 같은 지점(MsgSleep)에서 일어나므로, Critical·#MaxThreadsPerHotkey·Thread 우선순위가 그대로 적용됩니다.

예제

간단한 계산기 브릿지. index.html에서 버튼을 누르면 AHK가 더해 돌려줍니다.

; app.ahk
WebGui, Main:New, w720 h520, 내 앱
WebGui, Main:Expose, Add
WebGui, Main:On, __Ready, OnReady
WebGui, Main:Load, %A_ScriptDir%\index.html
WebGui, Main:Show
return

Add(params) {
    a := JGet(params, "a"), b := JGet(params, "b")
    return a + b          ; 문자열로 JS에 resolve
}
OnReady(params) {
    ToolTip, 페이지 준비됨
}
MainWebGuiClose:   ; 창 닫기
ExitApp
<!-- index.html -->
<button id="go">3 + 4</button><pre id="out"></pre>
<script>
  document.getElementById('go').onclick = async () => {
    const r = await ahk.call("Add", { a: 3, b: 4 });
    document.getElementById('out').textContent = "= " + r;
  };
  ahk.post("__Ready", {});
</script>
개발 모드: WebGui, Main:Load, http://localhost:5173로 Vite/webpack 개발 서버를 직접 띄우면 HMR을 그대로 쓸 수 있습니다. 배포 시 Load를 로컬 dist\index.html로 바꾸면 됩니다.

창 옵션 (New / Show)

stock Gui보다 웹 셸에 맞는 옵션을 지원합니다.

옵션설명
wNNN hNNN크기.
xNNN yNNN위치. 생략 시 작업 영역 중앙.
Center중앙 정렬.
-Resize크기 고정(두꺼운 테두리·최대화 제거).
Frameless테두리 없는 팝업. 타이틀바를 HTML로 직접 그릴 때.
AlwaysOnTop항상 위.
NoActivate표시 시 포커스를 뺏지 않음.
OpacityNNN0–255 창 투명도(레이어드 윈도우).

예: WebGui, Main:New, w1000 h700 Center AlwaysOnTop Opacity240, 대시보드

WebGuiGet — 페이지에서 값 가져오기

WebGuiGet, OutputVar, Name:SubCommand , Param3

WebGui가 AHK→웹 방향이라면, WebGuiGet은 웹→AHK로 값을 동기적으로 끌어옵니다(GuiControlGet과 같은 형태, OutputVar가 첫 인자).

Eval, JsCode
JS를 실행해 그 결과(JSON)를 OutputVar에 저장합니다. 메시지를 펌핑하며 결과를 기다리고(최대 5초), JSON 문자열은 따옴표를 벗겨 일반 문자열로, 그 외 JSON은 원형으로 반환합니다. 예: WebGuiGet, title, Main:Eval, document.title
Hwnd
웹 창의 핸들을 OutputVar에 저장합니다. stock WinMove·WinSet 등으로 웹 창을 제어할 수 있습니다.

단일 EXE 자산 번들링

스크립트 어딘가에 디렉티브를 넣으면, AhkWeb2Exe 컴파일 시 해당 폴더(React/Vue dist 등)를 EXE 안에 zip으로 내장합니다.

;@AhkWeb-Assets dist

실행 시 엔진이 자동으로 임시 폴더에 추출하고, 그 경로를 A_AhkWebAssets에 넣어줍니다. 아래 한 패턴으로 개발(소스)과 배포(단일 EXE)가 동일하게 동작합니다.

assets := A_AhkWebAssets ? A_AhkWebAssets : A_ScriptDir "\dist"
WebGui, Main:New, w1000 h700 Center
WebGui, Main:Mount, app.ahkweb, %assets%
WebGui, Main:Load, https://app.ahkweb/index.html
WebGui, Main:Show

컴파일하면 엔진 + 스크립트 + 웹 자산이 EXE 하나로 묶여, 외부 파일 없이 어디서나 실행됩니다.
